# Snag Photo Marker

A single-page mobile tool for logging snags against a floor plan.

- Load GA PDFs, find a room by name, drop a numbered pin per snag
- Add a description and up to three photos per snag, with markup
- Export one PDF: the plan with numbered markers, then a page per snag

Everything runs in the browser. Plans, photos and reports stay on the device.

The live page is served by GitHub Pages from `index.html` on `main`.
